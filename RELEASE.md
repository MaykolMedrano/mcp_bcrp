# Release and validation notes

## Current source state

The project uses `setuptools-scm` for its package version. A build from this
checkout produces version `0.3.0.dev2`; `_version.py` is regenerated by the
build process and is intentionally not committed, so the release tag controls
the public package version.

## Fixes validated in this working tree

- Search keeps economic terms such as `precio` and `valor`, while removing
  Spanish stopwords that do not identify a series.
- The `bcrp://metadata` resource reads the metadata dataframe correctly and
  returns a useful status before the catalog is loaded.
- `BCRP_TIMEOUT` configures both metadata and data requests, with a safe
  120-second default and validation for invalid values.
- Matplotlib is optional and is installed with the `charts` extra.
- The metadata catalog is cached per user and is not included in the package.

## Checks run

```text
python -m pytest -q
8 passed

python -m build --sdist --wheel
Successfully built mcp_bcrp-0.3.0.dev2
```

The built wheel was installed into an isolated target directory and imported
successfully. Its version matched the wheel metadata, and the metadata
resource returned the expected unloaded status without making a network call.

## Scope and limitations

The test suite uses local fixtures and does not replace an end-to-end check
against the live BCRP API. A full isolated virtual environment on Windows may
also be subject to local Application Control policies that block binary DLLs
such as pandas; that is an environment restriction, not a package error.
